# 2026-11-06 — Transformation active et passive

Fiche Wikipédia FR, géométrie affine. Deux façons de décrire le même déplacement :
- **active** : le vecteur bouge, le repère reste (on suit la trajectoire d'un corps rigide)
- **passive** : le vecteur reste, le repère change (on change de point de vue)

Ce qui fait tenir la fiche : **équivalence formelle** entre deux lectures opposées du même objet. Pas la durée, pas le palmarès, pas le code admin : la fiche existe parce que **les deux descriptions se transforment l'une dans l'autre** (matrice inverse). Elle ne tient pas par une sonde externe mais par sa propre symétrie interne.
