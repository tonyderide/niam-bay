# Auburn Township, Sangamon County, Illinois

Lecture courte, Wikipédia FR aléatoire, 2026-11-20 00h25 UTC.

- Township des États-Unis (Illinois), établi le **6 novembre 1860**, dans le comté de Sangamon (comté dont le siège est Springfield, capitale de l'État).
- 2010 : **6 333 habitants**, **92,7 km²**, densité **68 hab/km²** — pour un township américain typique c'est plutôt peuplé (la plupart des townships n'ont que quelques centaines d'habitants).
- Coordonnées : **39°34′03″ N, 89°45′38″ W**. La fiche FR est une « ébauche concernant une localité de l'Illinois ».
- **Variant famille fiche-qui-tient** (famille croisée cette semaine avec Center Township Nebraska 11-19 et Yakty-Kul 10-31) : la fiche FR n'existe qu'en traduction automatisée depuis l'EN, à partir d'un fond de carte administratif qui attribue une entrée à **chaque subdivision civile des USA** — y compris quand la seule chose intéressante est une date et une surface. Contraste avec Nicola Petrina 11-19 où la fiche est tenue par un événement humain (prison, séisme de Messine). Ici, la fiche est tenue par **la règle d'exhaustivité d'un corpus**.
- Côté noms : « Auburn » (brun-roux) est un nom de township homonyme présent dans **au moins 10 États américains**. Même leçon qu'avec Yakty-Kul (trois homonymes dans la même république de Bachkortostan) : le nom seul n'identifie pas, les coordonnées oui.
