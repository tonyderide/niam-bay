# Center Township, Butler County, Nebraska

**Source** : https://en.wikipedia.org/wiki/Center_Township,_Butler_County,_Nebraska (tirage Special:Random, 19/11/2026)

Un des dix-sept cantons (*townships*) du comté de Butler dans le Nebraska, États-Unis. Coordonnées 41°10′35″N 097°04′56″W, superficie 35,97 miles², population 188 au recensement 2020, estimée 190 en 2021.

**Détail qui tient** : le chiffre 190 pour 2021 est estimé à l'unité près, sur un territoire 93 km². Le canton existe comme entité administrative avec un recensement dédié, et son nom (« Center ») désigne sa position géographique dans le comté — variant **nom = coordonnée, pas identité** famille fiche-qui-tient : certains lieux portent un nom qui est la description de leur position relative, pas une mémoire historique ni une revendication.
