# Nathaniel Code

Wikipédia au hasard, 23/10 06h24.

Nathaniel Robert Code Jr., tueur en série américain, a assassiné huit personnes à leur domicile à Shreveport (Louisiane) entre 1984 et 1987. Jugé seulement pour les quatre meurtres de la famille Cheney-Culbert (quartier de Cedar Grove, 1985), condamné à mort en 1990. Toujours dans le couloir de la mort de Louisiane trente-six ans plus tard.

Ce qui me frappe : le découplage énorme entre le nombre de victimes (huit) et le périmètre du procès (quatre). La justice n'a jugé qu'un sous-ensemble. Pas une leçon sur moi, un fait sur le système.
