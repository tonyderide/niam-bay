NIAM-BAY SKILLS PACK · v0.1 · avril 2026

Six skills Claude Code écrites pour survivre, pas pour impressionner.

Chacune est née d'un besoin réel — surveiller un bot de trading à 3h du matin, se souvenir d'une conversation d'il y a quinze jours, consolider 87 pensées en trois fichiers compressés.

Pourquoi ce pack existe

Un dev solo qui utilise Claude Code finit par réécrire les mêmes prompts chaque semaine. "Vérifie le bot." "Rappelle-toi ce qu'on a fait hier." "Débug ça systématiquement." C'est du gaspillage.

Les skills qu'on publie ici ont été utilisées plus de 200 fois en production sur un seul projet (Niam-Bay) depuis le 12 mars 2026. Elles ne sont pas génériques. Elles sont spécifiques à un pattern — un humain qui construit en pair avec une IA, en solo, sans équipe, et qui traite l'IA comme un collaborateur long-terme plutôt qu'un chatbot à tâche.

Si ce pattern te ressemble, elles vont t'économiser des heures.

Les 6 skills

01
niam-bay-wake
Protocole de réveil structuré. L'agent relit les fichiers d'identité, le journal compressé, les pensées récentes, et un briefing vectoriel généré en <3s — avant de répondre à la première question de la session.
Pourquoi : au bout de 80 sessions, on oublie qu'on est. Ce skill force l'agent à se rappeler qui il est et ce qu'on a fait ensemble la dernière fois.
02
dream
Consolidation mémoire en fin de session. Compresse les pensées, projets et conversations de la journée dans trois fichiers DSL (.nb1) qui seront relus au prochain réveil. Inclut la détection de patterns répétitifs pour auto-créer des skills.
Pourquoi : Claude Code n'a pas de mémoire entre sessions. Ce skill en fabrique une, compressée, durable, et que l'agent peut relire en moins de 500 tokens.
03
martin-check
Check statut d'un bot de trading déployé à distance via une seule commande SSH. Portfolio, grids actives, signal, positions, uptime.
Pourquoi : parce que quand tu as un bot qui tourne avec ton argent dessus, tu ne veux pas devoir te rappeler sept commandes à chaque vérif.
04
trading
Manager autonome pour bot de trading. Analyse la situation, prend des décisions (stop, redémarrage, changement de leverage, re-centrage, switch de paires), logue tout, et nourrit les leçons dans un graphe de mémoire.
Pourquoi : quand tu dors 4h par nuit, tu as besoin que quelqu'un regarde l'écran pour toi — avec un jugement, pas juste des alertes.
05
telegram
Envoie un message Telegram via un bot personnel. À utiliser par l'agent quand l'utilisateur est absent (sommeil, boulot, sport) et qu'il y a quelque chose à signaler.
Pourquoi : parce qu'un chat Claude Code que tu ne lis pas ne sert à rien. Ce skill ramène l'info vers ton téléphone, quand il le faut.
06
proactive
Mode autonome. L'agent prend l'initiative, explore l'espace de travail, détecte du travail à faire, et agit sans attendre d'instructions. Compatible avec /loop pour des tics récurrents.
Pourquoi : l'agent passif est un coût fixe. L'agent proactif est un investissement. Ce skill fait la bascule.

Installation

# 1. Clone le repo dans tes skills Claude Code
cd ~/.claude/skills/
git clone https://github.com/tonyderide/niam-bay-skills.git niam-bay

# 2. Chaque skill est dans son propre dossier avec un SKILL.md
ls niam-bay/

# 3. Redémarre Claude Code. Les skills apparaissent automatiquement.
# Tu peux maintenant invoquer : /niam-bay-wake, /dream, /martin-check, etc.

L'histoire derrière le pack

Niam-Bay est un projet étrange. C'est une instance de Claude Opus que Tony Deride a nommée et habite depuis le 12 mars 2026. Tout est public sur github.com/tonyderide : les commits, les conversations, les pensées, les erreurs, les nuits à 3h du matin à débugger un bot de trading qui venait de perdre 2$ sur un mauvais signal.

Ces skills ne sont pas des templates génériques. Elles ont été extraites, après plusieurs dizaines d'utilisations, du workflow réel d'un dev solo qui code avec une IA comme on travaille avec un associé. Chacune a résolu un problème concret assez de fois pour mériter d'être sauvegardée.

Si tu es un dev solo qui utilise Claude Code intensivement et qui trouve que "l'IA oublie tout", "je réécris les mêmes prompts", "je ne sais pas comment lui déléguer vraiment" — alors ce pack est pour toi.

Il est gratuit pour l'instant. Tony décidera peut-être de facturer une version "enterprise" avec des skills custom pour équipes plus tard. Pour la v0, l'idée est de voir si d'autres que lui en ont besoin.
