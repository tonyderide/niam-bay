Critical Unsubscribed observables — memory leak in UserDashboardComponent

The component subscribes to userService.getUser() in ngOnInit but never unsubscribes. This creates a memory leak that grows every time the component is mounted. In a SPA with frequent navigation, this silently degrades performance over time.

// ❌ Before — leaks on every mount
ngOnInit() {
  this.userService.getUser().subscribe(u => this.user = u);
}

// ✅ After — cleaned up automatically
private destroy$ = new Subject<void>();

ngOnInit() {
  this.userService.getUser()
    .pipe(takeUntil(this.destroy$))
    .subscribe(u => this.user = u);
}

ngOnDestroy() {
  this.destroy$.next();
  this.destroy$.complete();
}
High ChangeDetectionStrategy.Default on all components — unnecessary re-renders

All 23 components use Angular's default change detection strategy. This means Angular checks every component on every browser event — mouse moves, keyboard presses, network responses. Switching to OnPush on components that only depend on @Input() values reduces CPU usage significantly in data-heavy views.

// ❌ Before — checks on every event
@Component({ selector: 'app-user-card', ... })
export class UserCardComponent { ... }

// ✅ After — only checks on reference changes
@Component({
  selector: 'app-user-card',
  changeDetection: ChangeDetectionStrategy.OnPush,
  ...
})
export class UserCardComponent { ... }
High HTTP calls directly in components — logic not reusable, testing impossible

ProductListComponent calls this.http.get('/api/products') directly. This couples the component to the transport layer, makes the logic unreusable from other components, and makes unit testing require a full HTTP mock. All HTTP calls belong in injectable services.

// ❌ Before — HttpClient injected directly in component
constructor(private http: HttpClient) {}
ngOnInit() {
  this.http.get<Product[]>('/api/products')
    .subscribe(p => this.products = p);
}

// ✅ After — delegated to a service
constructor(private productService: ProductService) {}
ngOnInit() {
  this.productService.getAll()
    .pipe(takeUntil(this.destroy$))
    .subscribe(p => this.products = p);
}
